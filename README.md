# Diagnóstico gratis · Empresa Inteligente
Node sin dependencias. `node server.js`. Variables: `ADMIN_CLAVE` (obligatoria para /admin), `DATA_DIR`, `NOTIFY_WEBHOOK_URL` (opcional), `HL_API_KEY` y `HL_LOCATION_ID` (opcionales, HighLevel).
Rutas: `/` página, `/api/diagnostico`, `/api/propuesta`, `/admin?clave=...`, `/healthz`.
